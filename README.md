# Car Audio Calculator

A handy, lightweight calculator built to help design, configure, and troubleshoot car audio systems. Whether you're sizing up power wire, matching amplifiers to subwoofers, or calculating enclosure specs, this tool makes the math quick and easy.

## Features
* **Power & Ohm's Law Calculations:** Easily determine current, voltage, impedance, and wattage.
* **Wiring & Electrical Sizing:** Check proper wire gauge requirements for amplifier loads (including Big 3 upgrades).
* **Enclosure & System Math:** Quick reference formulas for audio builds
